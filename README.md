# 🛒 Simple E-commerce Store

## 📌 Project Overview

This project is a simple and responsive **E-commerce Store** developed as part of the **CodeAlpha Full Stack Development Internship – Task 1**.

The website allows users to browse products, view product details, add products to a shopping cart, and manage cart items.

## 🚀 Features

- 🏠 Home page
- 🛍️ Product listing
- 🔍 Product details
- 🛒 Add products to cart
- ➕ Increase product quantity
- ➖ Decrease product quantity
- 🗑️ Remove products from cart
- 💰 Automatic total price calculation
- 📱 Responsive design
- 🎨 User-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
